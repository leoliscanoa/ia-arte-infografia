# Infografía: El impacto transformador de la IA en el arte

Esta infografía interactiva explora cómo la Inteligencia Artificial está transformando el mundo del arte, desde la creación hasta la difusión y análisis de obras artísticas.

## Características

- **Diseño Responsivo**: Adaptado para diferentes dispositivos y tamaños de pantalla
- **Navegación Secuencial**: Guía al usuario a través de los diferentes aspectos del impacto de la IA en el arte
- **Efectos Visuales**: Incluye animaciones y efectos visuales para mejorar la experiencia del usuario
- **Elementos Artísticos**: Incorpora elementos de diseño como manchas de pintura para reforzar la temática artística

## Tecnologías Utilizadas

- HTML5
- CSS3 (con animaciones y transiciones)
- JavaScript (para interactividad)
- TailwindCSS (para estilos)

## Cómo Ver la Infografía

Puedes ver la infografía de dos maneras:

1. **En línea**: Visita [https://leoliscanoa.github.io/ia-arte-infografia/](https://leoliscanoa.github.io/ia-arte-infografia/)
2. **Localmente**: Clona este repositorio y abre el archivo `index.html` en tu navegador
